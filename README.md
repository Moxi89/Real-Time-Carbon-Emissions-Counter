# Real-Time Carbon Emissions Counter

A web application that displays real-time global carbon emissions data with an elegant, dark-themed interface.

## Features

- Real-time tracking of global CO₂ emissions
- Elegant dark theme with green accents
- Responsive design
- Interactive counters with animations
- Environmental action suggestions
- Interactive charts showing emissions by country and sector
- Comprehensive FAQ section about carbon emissions
- Detailed disclaimer and data sources information

## Live Demo

Visit the live site: [CO₂ Emissions Counter](https://carbonemissionscounter.netlify.app/)

## Technology Stack

- HTML5, CSS3, JavaScript
- Chart.js for data visualization
- Real-time updates using JavaScript
- Responsive and mobile-friendly design
- Dark theme with elegant animations

## Local Development

1. Clone this repository:
   ```bash
   git clone [your-repo-url]
   cd Real-Time-Carbon-Emissions-Counter
   ```

2. Open the `index.html` file in your web browser

## Deployment

This project is deployed using Netlify for optimal performance and reliability.

### Deploy your own version

1. Fork this repository
2. Sign up on [Netlify](https://app.netlify.com)
3. Choose "Import an existing project"
4. Connect your GitHub account and select this repository
5. Configure build settings:
   - Build command: `cp -r static templates/`
   - Publish directory: `templates`
6. Click "Deploy site"
